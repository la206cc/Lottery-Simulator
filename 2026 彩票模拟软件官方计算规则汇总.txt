### 1. 双色球（福彩）
#### 基础规则
- 玩法：红球33选6 + 蓝球16选1
- 单注价格：2元
- 奖金计提：销售额的51%为奖金（49%当期奖金，2%调节基金）

#### 核心计算逻辑
```python
# 基础变量
当期奖金 = 销售额 * 0.49
固定奖总额 = 当期所有固定奖的派奖总和
浮动奖基数 = 当期奖金 - 固定奖总额
奖池 = 上期奖池余额 + 滚存资金

# 规则触发：奖池≥15亿时启动特别规定，<3亿时停止
if 奖池 >= 1500000000:
    # 特别规定期
    一等奖总额 = 奖池 + 浮动奖基数 * 0.2
    二等奖总额 = 浮动奖基数 * 0.8
    新增福运奖：3红0蓝，固定5元
else:
    # 常规期
    if 奖池 < 100000000:
        一等奖总额 = 浮动奖基数 * 0.75 + 奖池
    else: # 1亿 ≤ 奖池 <15亿
        part1 = 浮动奖基数 * 0.55 + 奖池
        part2 = 浮动奖基数 * 0.2
        一等奖总额 = part1 + part2
    二等奖总额 = 浮动奖基数 * 0.25

# 封顶规则
if 一等奖总额 > 100000000: # 单期一等奖总奖金封顶1亿
    一等奖单注 = 100000000 / 一等奖中奖注数
else:
    一等奖单注 = 一等奖总额 / 一等奖中奖注数
if 二等奖总额 > 70000000: # 单期二等奖总奖金封顶7000万
    二等奖单注 = 70000000 / 二等奖中奖注数
else:
    二等奖单注 = 二等奖总额 / 二等奖中奖注数

# 保底规则
if 一等奖单注 < 二等奖单注 * 2 and 一等奖单注 <5000000:
    一等奖单注 = 二等奖单注 *2
if 二等奖单注 < 6000: # 三等奖的2倍
    二等奖单注 =6000
```

#### 固定奖详情
| 奖级 | 中奖条件 | 固定奖金 |
|------|----------|----------|
| 三等奖 | 5红+1蓝 | 3000 |
| 四等奖 | 5红+0蓝 /4红+1蓝 | 200 |
| 五等奖 |4红+0蓝 /3红+1蓝 |10 |
| 六等奖 | 中蓝球即可 |5 |
| 福运奖（仅特别期） |3红+0蓝 |5 |

### 2. 超级大乐透（体彩）
#### 基础规则
- 玩法：前区35选5 + 后区12选2，支持1元追加投注
- 单注价格：2元（追加+1元）
- 奖金计提：销售额的51%为奖金（49%当期奖金，2%调节基金）

#### 核心计算逻辑
```python
# 基础变量
当期奖金 = 销售额 *0.49
固定奖总额 = 当期所有固定奖的派奖总和
浮动奖基数 = 当期奖金 - 固定奖总额
奖池 = 上期奖池余额 + 滚存资金

# 固定奖触发：奖池≥8亿时，固定奖全面提升
if 奖池 >=800000000:
    三等奖=13332;四等奖=380;五等奖=200;六等奖=18;七等奖=7
else:
    三等奖=10000;四等奖=300;五等奖=200;六等奖=15;七等奖=5

# 一等奖分档计算
if 奖池 <100000000:
    一等奖总额 = 浮动奖基数 *0.78 + 奖池
elif 100000000 <= 奖池 <800000000:
    part1 = 浮动奖基数 *0.58 + 奖池
    part2 = 浮动奖基数 *0.2
    一等奖总额 = part1 + part2
else: # 奖池≥8亿
    part1 = 浮动奖基数 *0.28 + 奖池
    part2 = 浮动奖基数 *0.5
    一等奖总额 = part1 + part2
二等奖总额 = 浮动奖基数 *0.22

# 封顶规则
if 一等奖总额 >100000000: # 单期一等奖总奖金封顶1亿
    一等奖单注 =100000000 / 一等奖中奖注数
else:
    一等奖单注 = 一等奖总额 / 一等奖中奖注数
二等奖单注 = 二等奖总额 / 二等奖中奖注数

# 追加规则：浮动奖可额外获得80%奖金
追加单注奖金 = 基本单注奖金 *0.8
```

| 三等奖 |5+0 /4+2 |10000 |13332 |
| 四等奖 |4+1 |300 |380 |
| 五等奖 |4+0 /3+2 |200 |200 |
| 六等奖 |3+1 /2+2 |15 |18 |
| 七等奖 | 中后区即可 |5 |7 |

### 4. 七星彩（体彩）
#### 基础规则
- 玩法：前6位0-9各选1 + 后区14选1
- 单注价格：2元
- 奖金计提：销售额的50%为奖金（49%当期奖金，1%调节基金）

#### 核心计算逻辑
```python
# 基础变量
当期奖金 = 销售额 *0.49
固定奖总额 = 3000*三等奖注数 +500*四等奖注数 +30*五等奖注数 +5*六等奖注数
浮动奖基数 = 当期奖金 - 固定奖总额
奖池 = 上期奖池余额

# 奖池>3亿时，浮动奖比例倒置
if 奖池 >300000000:
    一等奖总额 = 浮动奖基数 *0.1 + 奖池
    二等奖总额 = 浮动奖基数 *0.9
else:
    一等奖总额 = 浮动奖基数 *0.9 + 奖池
    二等奖总额 = 浮动奖基数 *0.1

一等奖单注 = 一等奖总额 / 一等奖注数
二等奖单注 = 二等奖总额 / 二等奖注数

# 封顶：单注最高500万
一等奖单注 = min(一等奖单注,5000000)
二等奖单注 = min(二等奖单注,5000000)
```

### 8. 快乐8（福彩）
#### 基础规则
- 玩法：80个号码摇出20个，支持选1-选10共10种玩法
- 单注价格：2元
- 奖金计提：销售额的58%为奖金（57%当期，1%调节）

#### 核心计算逻辑（选十/选九浮动奖）
```python
# 基础变量
选九选十计提 = 销售额 *0.57 * 对应玩法占比
固定奖总额 = 当期选九选十的固定奖派奖总和
浮动奖基数 = 选九选十计提 - 固定奖总额
奖池 = 上期浮动奖奖池余额

# 浮动奖计算
理论封顶总额 = 250000*选九中九注数 +5000000*选十中十注数
if (浮动奖基数 + 奖池) >= 理论封顶总额:
    选九中九单注 =250000
    选十中十单注 =5000000
else:
    比例 = (浮动奖基数 + 奖池) / 理论封顶总额
    选九中九单注 =250000 * 比例
    选十中十单注 =5000000 * 比例

# 单期总封顶
if (选九中九单注*选九注数 + 选十中十单注*选十注数) >100000000:
    总封顶比例 = 100000000 / (选九中九单注*选九注数 + 选十中十单注*选十注数)
    选九中九单注 *= 总封顶比例
    选十中十单注 *= 总封顶比例

# 保底
if 选十中十单注 < 8000*2: # 选十中九的2倍
    选十中十单注 =16000
if 选九中九单注 <2000*2: # 选九中八的2倍
    选九中九单注 =4000
```

| 选十 | 中8 |720 |
| 选十 | 中7 |80 |
