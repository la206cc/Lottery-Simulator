## 一、双色球

### 购买规则
- **号码组成**：从红色球号码区（1-33）选择6个号码，从蓝色球号码区（1-16）选择1个号码
- **单注金额**：2元
- **投注方式**：
  - 单式投注：标准的6+1组合
  - 复式投注：红球选7个以上或蓝球选2个以上
  - 胆拖投注：选取胆码和拖码组合
  - 多倍投注：2-99倍

### 开奖规则
- **开奖时间**：每周二、四、日（休市日除外）
- **开奖方式**：先摇出6个红色球号码，再摇出1个蓝色球号码

### 中奖规则（顺序不限）
| 奖级 | 中奖条件 | 奖金 |
|------|----------|------|
| 一等奖 | 6红+1蓝全中 | 浮动奖，单注最高1000万元，单期总额封顶1亿元 |
| 二等奖 | 6红全中 | 浮动奖，单注最高500万元，单期总额封顶7000万元 |
| 三等奖 | 5红+1蓝 | 3000元 |
| 四等奖 | 5红 或 4红+1蓝 | 200元 |
| 五等奖 | 4红 或 3红+1蓝 | 10元 |
| 六等奖 | 1蓝 | 5元 |
| 福运奖 | 3红（奖池≥15亿元时） | 5元 |

### 浮动奖金详细计算

#### 基础变量定义
| 变量名 | 计算公式 | 说明 |
|--------|----------|------|
| 彩票奖金总额 | 当期销售总额 × 51% | 销售额的51%作为奖金池 |
| 当期奖金 | 当期销售总额 × 51% × 49% | 奖金池的49%用于当期派奖 |
| 调节基金 | 当期销售总额 × 51% × 2% | 奖金池的2%作为调节基金 |
| 固定奖总额 | ∑(各固定奖级单注奖金 × 该奖级中奖注数) | 当期所有固定奖的派奖总和 |
| 浮动奖基数 | 当期奖金 - 固定奖总额 | 扣除固定奖后剩余的浮动奖金 |
| 奖池 | 上期奖池余额 + 滚存资金 | 累积的奖池资金 |

#### 常规期（奖池 < 15亿元）浮动奖金计算
| 奖池条件 | 奖级 | 奖金总额计算公式 | 单注奖金计算公式 | 单注封顶 |
|----------|------|------------------|------------------|----------|

|  | 二等奖 | 浮动奖基数 × 25% | 二等奖总额 ÷ 二等奖中奖注数 | 500万元 |
| 1亿元 ≤ 奖池 < 15亿元 | 一等奖第一部分 | 浮动奖基数 × 55% + 奖池 | 一等奖第一部分 ÷ 一等奖中奖注数 | 500万元 |
|  | 一等奖第二部分 | 浮动奖基数 × 20% | 一等奖第二部分 ÷ 一等奖中奖注数 | 500万元 |
|  | 一等奖合计 | 一等奖第一部分 + 一等奖第二部分 | (一等奖第一部分 + 一等奖第二部分) ÷ 一等奖中奖注数 | 1000万元 |
|  | 二等奖 | 浮动奖基数 × 25% | 二等奖总额 ÷ 二等奖中奖注数 | 500万元 |

#### 单期总额封顶规则
| 奖级 | 封顶金额 | 触发条件 | 触发后单注奖金计算公式 |
