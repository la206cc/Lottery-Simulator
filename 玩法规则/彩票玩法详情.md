## 一、双色球

### 购买规则
- **号码组成**：从红色球号码区（1-33）选择6个号码，从蓝色球号码区（1-16）选择1个号码
- **单注金额**：2元
- **投注方式**：
  - 单式投注：标准的6+1组合
  - 复式投注：红球选7个以上或蓝球选2个以上
  - 胆拖投注：选取胆码和拖码组合
  - 多倍投注：2-99倍

### 开奖规则
- **开奖时间**：每周二、四、日（休市日除外）
- **开奖方式**：先摇出6个红色球号码，再摇出1个蓝色球号码

### 中奖规则（顺序不限）
| 奖级 | 中奖条件 | 奖金 |
|------|----------|------|
| 一等奖 | 6红+1蓝全中 | 浮动奖，单注最高1000万元，单期总额封顶1亿元 |
| 二等奖 | 6红全中 | 浮动奖，单注最高1000万元，单期总额封顶7000万元 |
| 三等奖 | 5红+1蓝 | 3000元 |
| 四等奖 | 5红 或 4红+1蓝 | 200元 |
| 五等奖 | 4红 或 3红+1蓝 | 10元 |
| 六等奖 | 1蓝 | 5元 |
| 福运奖 | 3红（奖池≥15亿元时） | 5元 |

**特别规定**：当奖池资金≥15亿元时启动，增设"福运奖"，命中3个红球即可获得5元奖金，持续至奖池低于3亿元时停止。

## 五、七星彩

### 购买规则
- **号码组成**：前6位从000000-999999中选，最后一位从0-14中选
- **单注金额**：2元
- **投注方式**：单式、复式、多倍（2-99倍）

### 开奖规则
- **开奖时间**：每周二、五、日
- **开奖方式**：按顺序摇出6位前区数字和1位后区数字

| 奖级 | 中奖条件 | 奖金 |

## 六、排列三

### 购买规则
- **号码组成**：从000-999中选择1个3位数
- **单注金额**：2元
- **投注方式**：
  - 直选：号码顺序固定
  - 组选3：3位数中有2位相同（3种排列）
  - 组选6：3位数各不相同（6种排列）
  - 多倍投注：2-99倍

### 开奖规则
- **开奖时间**：每天
- **开奖方式**：以排列五当期开奖号码的前三位作为开奖号码

### 中奖规则
| 投注方式 | 中奖条件 | 奖金 |
|----------|----------|------|
| 直选 | 号码与开奖号码数字相同且顺序一致 | 1040元 |
| 组选3 | 开奖号码有2位相同，投注号码数字相同（顺序不限） | 346元 |
| 组选6 | 开奖号码各不相同，投注号码数字相同（顺序不限） | 173元 |

## 八、福彩3D

### 购买规则
- **号码组成**：从000-999中选择1个3位数
- **单注金额**：2元
- **投注方式**：单选、组选3、组选6、1D、2D、和数、猜大小等13种

### 开奖规则
- **开奖时间**：每天
- **开奖方式**：按百位、十位、个位顺序摇出3位数

### 主要中奖规则

| 单选 | 投注号码与开奖号码按位全部相同 | 1040元 |
| 组选3 | 开奖号码有2位相同，投注号码数字相同（顺序不限） | 346元 |
| 组选6 | 开奖号码各不相同，投注号码数字相同（顺序不限） | 173元 |
| 1D | 投注号码与开奖号码中对应位置号码相同 | 10元 |
| 2D | 投注号码与开奖号码中对应两个位置号码按位相同 | 104元 |
| 和数 | 投注号码与开奖号码三个数字之和相同 | 14-1040元 |
| 猜大小 | 投注与开奖号码和的大小性质相同（0-8小，19-27大） | 6元 |
