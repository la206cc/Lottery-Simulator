## 玩法规则深度分析

用户提醒需要先研究玩法规则，特别是：
1. 资金计算的精细逻辑（容易出错）
2. 确保自定义参数能完整复现官方彩种

### 完成的分析工作
- 阅读了全部玩法规则文档（2026官方计算规则汇总、双色球、大乐透、快乐8、七乐彩等）
- 分析了v2.0前端和后端的所有奖金计算代码
- 发现了6大已知坑点：
  1. 双色球/大乐透「两部分封顶」（每部分独立封顶500万，可达1000万）
  2. 保底规则的级联效应（后触发的可能覆盖先触发的）
  3. 大乐透保底与双色球不同（动态值 vs 固定值）
  4. 大乐透追加投注的1.8倍计算
  5. 七星彩倒置规则
  6. 福彩3D/排列三的按位/不按位匹配逻辑

### 前后端不一致问题
- 福彩3D/排列三后端match_pattern全为[[3]]，无法区分直选/组三/组六
- 快乐8后端只定义了选十玩法
- 双色球前端无二等奖maxTotal
- 福运奖前端有描述但后端无实现

详细分析报告已保存到：`v3.0-参数需求分析.md`

## 完整参数系统设计

基于用户要求，设计了一个完整的参数系统，确保：
1. 能完整复现8种官方彩种
2. 支持用户自定义全新彩票类型

### 参数系统架构（5大类）

| 类别 | 职责 | 参数数量 |
|------|------|----------|
| A类：彩票规则配置 | 定义彩票基础规则（区域、玩法） | ~30个 |
| B类：奖金分配配置 | 定义奖金分配逻辑（奖级、封顶、保底） | ~40个 |
| C类：投注模拟配置 | 模拟用户投注行为（类型分布、倍投） | ~15个 |
| D类：用户行为配置 | 模拟不同购彩人群（频率、选号策略） | ~20个 |
| E类：系统控制配置 | 模拟控制参数（期数、存储、输出） | ~10个 |

### 关键发现

1. **两部分封顶机制**：双色球/大乐透高奖池时，一等奖分两部分，每部分独立封顶500万
2. **保底级联规则**：必须先计算保底再应用封顶，否则可能超过限制
3. **大乐透追加机制**：追加中奖按1.8倍计算，封顶900万
4. **七星彩倒置规则**：奖池>3亿时，一二等奖比例倒置

## 阶段三完成：核心引擎适配（可扩展架构设计）

贯彻"方便修改"的设计原则，实现了可扩展的核心引擎架构。

### 设计原则
1. **策略模式**：支持不同的生成规则和计算逻辑
2. **工厂模式**：创建不同类型的组件
3. **依赖注入**：解耦组件之间的依赖
4. **配置驱动**：动态选择计算逻辑
5. **插件式扩展**：支持自定义扩展

### 实现的组件

#### 1. 核心引擎接口和抽象层 (`src/core/base.py`)
- `NumberZone`：号码区域配置
- `PrizeTier`：奖级配置
- `LotteryConfig`：彩票配置
- `BaseNumberGenerator`：号码生成器抽象基类
- `BasePrizeCalculator`：奖金计算器抽象基类
- `BaseBetSimulator`：投注模拟器抽象基类
- `BaseDataAnalyzer`：数据分析器抽象基类
- `BaseDataStorage`：数据存储器抽象基类
- `ComponentFactory`：组件工厂
- `ConfigLoader`：配置加载器

- `DefaultPrizeCalculator`：默认奖金计算器

- `DLTPrizeCalculator`：大乐透计算器（特殊规则）

- `QXCPrizeCalculator`：七星彩计算器（倒置规则）
- 支持规则：固定奖金、浮动奖金、奖池分档、保底、追加、倒置、两部分封顶

- `DefaultBetSimulator`：默认投注模拟器
- `StrategyBetSimulator`：策略投注模拟器
- `BatchBetSimulator`：批量投注模拟器
- 支持功能：单式/复式/胆拖、倍投、追加、多轮次模拟、策略模拟

#### 5. 通用数据分析模块 (`src/core/analyzers.py`)
- `DefaultDataAnalyzer`：默认数据分析器
- 支持分析：号码频率、遗漏值、趋势、奖金分布、号码组合、连号

#### 6. 通用数据存储模块 (`src/core/storages.py`)
- `DefaultDataStorage`：默认数据存储器（JSON）

- `CSVDataStorage`：CSV格式存储器

### 配置分离结构

**彩票规则配置** (`config-editor.html`):
- 基础信息（ID、名称、价格）
- 号码区域配置
- 玩法类型配置
- 奖级设置
- 奖池分档
- 保底规则
- 特殊功能（追加、特别号码、倒置）

**投注模拟配置** (`bet-config-editor.html`):
- 投注类型分布（单式/复式/胆拖占比）
- 倍数分布（1倍/2-5倍/6-20倍/20+倍占比）
- 用户行为（购彩频率、选号策略）
- 号码特征（热号/冷号、生日范围、区间分布）
- 销量配置（基础销量、波动、趋势）
- 投注限制（最大注数、最大金额）

### 技术实现

1. **配置分离**: 两个编辑器独立管理不同类型的配置
2. **数据共享**: 通过localStorage共享配置数据
3. **配置同步**: 保存时自动同步配置到用户配置
4. **界面导航**: 主页提供快捷链接跳转
