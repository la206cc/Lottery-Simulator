# 彩票模拟器项目 - 长期记忆

## 项目基本信息
- **项目名称**: Lottery-Simulator (彩票摇号模拟器)
- **项目路径**: C:\Users\elex\Desktop\彩票模拟器\Lottery-Simulator
- **Git 仓库**: git@github.com:la206cc/Lottery-Simulator.git
- **主要版本**: v2.0 (当前开发版本)

## 技术架构
- **前端**: Electron + HTML/CSS/JavaScript
- **后端**: Python (NumPy, Pandas, PyArrow)
- **数据格式**: Parquet
- **构建工具**: electron-builder

## 支持的彩票类型
1. 双色球 (ssq)
2. 超级大乐透 (dlt) 
3. 福彩3D (fc3d)
4. 七星彩 (qxc)
5. 排列三 (pls)
6. 排列五 (plw)
7. 七乐彩 (qlc)
8. 快乐8 (kl8)

- v2.0/js/app.js: 主要前端逻辑 (182KB)

- **核心引擎**: 可扩展的组件化架构

## 投注模拟参数系统
- **参数分类**: 5层参数体系（人群结构、投注方式、倍投分布、选号特征、内部结构）
- **预设方案**: 保守型、均衡型、激进型、官方数据型
- **彩种适配**: 根据彩种特性自动调整可用参数
- **可视化**: 条形图、滑块、圆形图表展示参数占比
