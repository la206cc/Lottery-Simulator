# 适配 3D / 排列三

所有参数附带**真实占比 / 取值规则**，可直接编码落地，保证模拟数据贴近真实购彩行为。

## 一、全局市场参数（单期整体量级）

1. **总投注人数**：取值区间 80 万～150 万
2. **单期总投注金额**：取值区间 3000 万～8000 万元（单注固定 2 元，可反推总注数）
3. **波动系数**：±8%（模拟每日正常销量浮动）

## 二、用户分层参数（决定投注风格，2 个核心维度）

### 1. 购彩频次（决定投注金额、玩法偏好）

- 高频玩家（每日购彩）：15% → 大额、偏爱复式 / 胆拖、倍投多，贡献约 40% 销量
- 中频玩家（每周 1\~2 次）：35% → 中等投注，单式 + 少量复式
- 低频玩家（偶尔购买）：50% → 小额、以单式、机选为主

### 2. 选号思路（直接影响号码冷热分布）

- 随机 / 机选：45% → 号码分布相对均匀
- 守固定号码：35% → 长期重复使用同一组号码
- 参考走势（追热 / 追冷）：20% → 偏向近期开出的热门号、长期未出的冷门号

## 三、玩法类型占比（核心，区分直选 / 组选）

按投注注数统计占比：

1. 直选：55%
2. 组六：30%
3. 组三：8%
4. 小众附加玩法：7%（排列三可直接剔除）

## 四、投注形式参数（单式 / 复式 / 胆拖）

基于上述玩法再细分：

1. 单式投注：40%
2. 定位复式（直选专用）：35%
3. 组选复式：15%
4. 胆拖投注：10%

## 五、倍投参数（全玩法通用）

- 1 倍：70%
- 2\~5 倍：25%
- 6\~20 倍：4.5%
- 20 倍以上：0.5%（大额用户）

## 六、单用户投注规模（单期个人注数 / 金额）

### 1. 单用户当期注数

- 1\~5 注：60%
- 6\~20 注：30%
- 21\~100 注：8%
- 100 注以上：2%

### 2. 单用户当期投注金额

- ＜10 元：40%
- 10\~50 元：45%
- 50\~200 元：12%
- ＞200 元：3%

## 七、选号特征参数（决定最终号码分布，重中之重）

### 1. 数字偏好（0-9）

热门数字 (1,5,6,8,9)：选中概率上浮 15%

&#x20;冷门数字 (0,4,7)：选中概率下调 10%

### 2. 和值偏好（3D / 排列三和值范围 0\~27）

- 中间和值（8\~19）：70%
- 小和值（0\~7）：10%
- 大和值（20\~27）：20%

### 3. 奇偶 / 大小形态

大小：0-4 为小，5-9 为大

- 两奇一偶 / 两偶一奇：75%
- 全奇 / 全偶：25%
- 大小分布比例与奇偶一致

### 4. 复式选号规则（编码直接套用）

- 直选定位复式：单位置多选集中在 2\~3 个号，4 个及以上仅占 5%
- 组六复式：选 4\~5 个号为主，6 码及以上占比极低

### 5. 胆拖规则

- 组选胆拖：1 胆 + 拖码（70%）、2 胆 + 拖码（30%）
