# 投注模拟参数总结整理

> 本文档整合大乐透、福彩3D、排列三、快乐8、排列五、七乐彩、七星彩、双色球共8个彩种的彩民购买行为数据，完成结构化表格整理、参数冲突检测与合理性分析。

---

## 一、分析方法说明

### 1.1 求和校验原则

对每一组百分比参数（同一维度下的子项占比），进行**100%闭合校验**：若子项总和 ≠ 100%，则标记为冲突，并优先以更细分维度的数据（如按购彩频次分层的内部权重）作为基准。

### 1.2 冲突处理优先级

当文档中不同位置的参数数值存在冲突时，遵循以下优先级：

1. **按频次分层推导值 > 直接给出的汇总值**（更细分的数据反映更真实的分布）
2. **内部权重拆分方案 > 单一汇总数值**（因为内部权重经过归一化设计，逻辑自洽）
3. **文档中明确标注"可直接编码"的方案 > 概览性描述**

### 1.3 跨维度关联分析

以下是彩民行为数据中的核心维度及其关联关系：

```
购彩频次（高/中/低频）
    ├── 影响 → 投注方式（单式/复式/胆拖）
    ├── 影响 → 倍投倍数选择
    ├── 影响 → 单期投注金额
    └── 影响 → 选号思路（机选/自选/走势/守号）

投注方式（单式/复式/胆拖）
    ├── 与 玩法类型（如3D的直选/组选）存在交叉
    └── 复式内部有固定的规模分布

选号思路（机选/自选/走势/守号）
    └── 间接影响 → 号码冷热分布
```

**关键计算逻辑**：总体投注方式占比 = Σ(各频次人群占比 × 该人群的投注方式选择比例)。但由于文档给出的频次分层描述为定性而非定量（如"多复式/胆拖"），无法直接通过该公式反推精确数值。因此，本文仅在有**数值型细分数据**时采用推导结果替代汇总值。

## 二、各彩种核心参数冲突检测与处理

### 2.1 快乐8：玩法占比冲突（重要）

#### 冲突表现

**合计 = 105%，超出 100%，存在数据冲突**。

| 玩法 | 计算式 | 占比 | | 玩法 | 计算式 | 占比 |
|------|--------|------|------|------|--------|------|

**校验**：2.0+4.0+7.0+12.0+19.8+18.0+12.0+10.2+4.95+10.05 = **100.0%** ✓

#### 处理结论

**以滑块方案（第二段）数据为准**，原因：
1. 第一段数据总和为 105%，不符合百分比闭合要求
2. 第二段数据总和严格为 100%，且内置了内部权重拆分逻辑
3. 第二段数据明确标注为"可直接编码"的方案，设计意图更明确
4. 第二段数据与高中低频彩民行为描述一致（低频→选一~四，中频→选四~七，高频→选五~八+选九/十）

### 2.2 排列五：投注形式分类问题

#### 问题表现

排列五文档"三、投注形式占比"中将"倍投5%"列为投注形式：

> - 单式（5位直选）：95%
> - 倍投：5%（高频用户为主）

#### 分析

排列五只有**直选**一种下注方式，不存在复式、胆拖等形式。"倍投"属于**倍数选择维度**，与"投注形式"是不同维度，不应在同一维度内合并计数。

排列五另有独立的倍投分布参数：

| 倍数 | 1倍 | 2-5倍 | 6-10倍 | 10倍以上 |
|------|------|-------|--------|----------|
| 占比 | 80% | 17%   | 2.5%   | 0.5%     |

#### 处理结论

- **投注形式维度**：排列五统一为 100% 单式（5位直选），不存在复式/胆拖分类
- **倍投维度**：独立使用"四、倍投分布"参数表（1倍80%、2-5倍17%、6-10倍2.5%、10倍以上0.5%）
- 原文档中"倍投5%"数值**不纳入**投注形式维度统计，可能指向特定高倍投行为，但因其含义模糊且在独立倍投表中已有精确数据，建议忽略该数值

## 四、购彩频次与投注方式占比的关联机制分析

### 4.1 理论模型

总体投注方式占比的计算公式为：

```
总体单式占比 = Σ(频次人群占比 × 该人群选单式的概率)
总体复式占比 = Σ(频次人群占比 × 该人群选复式的概率)
总体胆拖占比 = Σ(频次人群占比 × 该人群选胆拖的概率)
```

### 4.2 各彩种频次分层与投注方式关联定性分析

#### 大乐透

| 频次 | 人群占比 | 投注方式偏好 | 对总体影响 |
|------|:------:|-------------|------------|
| 高频 | 10% | 多复式/胆拖、倍投、追加 | 拉高复式+胆拖占比约12-15个百分点 |
| 中频 | 40% | 单式+少量复式，追加率中等 | 主力人群，贡献约50%单式占比 |
| 低频 | 50% | 小额、机选为主，追加率低 | 拉高单式占比约40-45个百分点 |

**推导验证**：若高频10%中约70%选复式/胆拖、中频40%中约25%选复式/胆拖、低频50%中约10%选复式/胆拖，则：
- 复式+胆拖总体 ≈ 10%×70% + 40%×25% + 50%×10% = 7% + 10% + 5% = **22%**
- 单式总体 ≈ **78%**

但文档给出的单式值为55%，这说明实际高频+中频的复式/胆拖选择率远高于上述简化假设，这与"贡献约30%销量"的销量加权效应一致——高频用户虽然人数仅10%，但其注数多、金额大，按注数统计复式占比会被显著放大。

**结论**：55%单式占比是合理的。因为投注形式占比按**注数**而非**人数**统计，高频用户的单注中复式比例高且注数多，在注数加权下会大幅拉高复式占比。

#### 七星彩

| 频次 | 人数占比 | 行为特征 | 
|------|:------:|----------|
| 高频(8%) | 8% | 多复式、倍投，贡献25%销量 |
| 中频(37%) | 37% | 单式+少量复式 |
| 低频(55%) | 55% | 小额、机选为主 |

70%单式占比与55%低频+37%中频偏单式+8%高频偏复式的结构一致。

#### 双色球

| 频次 | 人数占比 | 行为特征 |
|------|:------:|----------|
| 高频(12%) | 12% | 多复式/胆拖、倍投，贡献35%销量 |
| 中频(38%) | 38% | 单式+少量复式 |
| 低频(50%) | 50% | 小额、机选为主 |

60%单式+40%复式/胆拖的分布与频次结构吻合。

### 4.3 频次-倍投关联分析

高频用户倾向于使用更高倍数。以福彩3D/排列三为例验证：

| 频次 | 人数占比 | 倍投偏好 | 销量贡献 |
|------|:------:|----------|:------:|
| 高频 | 15% | 大额、倍投多 | 40% |
| 中频 | 35% | 中等投注 | - |
| 低频 | 50% | 小额、单式为主 | - |

高频15%人贡献40%销量，说明其平均注数约为低频的 (40%/15%) / (剩余60%/85%) ≈ 3.8倍。倍投分布中1倍占70%、2倍以上合计占30%，与"高频贡献大额销售"的逻辑一致——倍投>1的用户主要集中在高频人群中。

## 七、数据使用建议

### 7.1 编码时的参数取值优先级

1. **快乐8玩法占比**：使用第五节滑块方案默认值
2. **排列五投注形式**：统一为100%单式直选，倍投维度单独使用倍投参数表
3. **福彩3D/排列三**：排列三需剔除"小众附加玩法7%"，将直选/组六/组三按比例归一化（直选59.1%/组六32.3%/组三8.6%）
4. **其余彩种**：直接使用文档原始参数，均已通过100%校验

### 7.2 各维度权重在模拟中的使用方式

```
生成一个彩民时，按以下顺序采样：

1. 购彩频次 → 决定该彩民是高/中/低频
2. 选号思路 → 按频次分层调整选择概率
3. 玩法类型 → 按彩种规则确定（3D/排列三/快乐8有玩法选择）
4. 投注形式 → 单式/复式/胆拖，按频次分层调整
5. 复式规模 → 若选复式，按内部结构采样码数
6. 倍投倍数 → 按倍投分布采样
7. 追加与否 → 仅大乐透
8. 号码生成 → 按号码特征参数生成具体号码
```
