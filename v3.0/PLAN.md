# V3.0 通用彩票模拟器 - 重规划方案

融合 v2.0 的深色主题 + 左侧栏 + 多Tab架构，结合 docs 文件夹中的分人群参数调节面板（滑块联动、波动算法、100%闭合），打造一个通用的专业级彩票模拟器。

## 五、参数面板核心机制 (来自 docs)

### 5.1 滑块联动算法
每组滑块值自动归一化，拖动任意一个滑块，其他滑块按比例分配差值，保证总和恒为100%。

### 5.2 权重自适应波动
基于 `getAdaptiveWeightNoise` 算法：小占比自动收窄波动范围，大占比承载主要波动，总偏移恒为0保证100%闭合。

### 5.3 分人群 + 全局汇总
```
全局投注形式 = Σ(频次人群占比 × 该人群的投注形式选择比例)
```
先按高/中/低频各自设定投注行为模板，再按人群占比加权汇总。

## 六、8种彩种参数差异化

| 彩种 | 特有参数 | 默认数据来源 |
|------|----------|-------------|
| 双色球 | 红球复式拆分(7红/8-9红/10-12红)、胆拖拆分 | docs/双色球 参数模板 |

| 排列三 | 同上(剔除小众7%) | docs/福彩3D-排列三 |
| 排列五 | 无复式(100%直选)、独立倍投表 | docs/排列五 参数模板 |
| 七星彩 | 前区复式/后区复式拆分 | docs/七星彩 参数模板 |
| 七乐彩 | 复式(8-12码)/胆拖内部结构 | docs/七乐彩 参数模板 |
| 快乐8 | 3滑块(L/M/H)×内部权重、10种玩法 | docs/快乐8 参数模板 |

## 七、数据流架构

```
用户选择彩种 → 加载该彩种的默认参数
       ↓
调整参数面板(滑块联动+波动)
       ↓
点击"开始模拟" → 后端引擎模拟
       ↓
接收结果 → 展示表格 + 统计栏 + 图表
       ↓
可导出(CSV/JSON)或导入对比
```
