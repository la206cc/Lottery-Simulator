# 投注模拟参数系统设计文档

> 本文档基于现有投注参数方案重新设计通用投注模拟配置系统

---

## 一、现有方案总结

### 1.1 方案特点

现有投注参数模板采用**分层设计**：

1. **人群结构层**：高频/中频/低频彩民占比
2. **行为模板层**：每类人群的投注方式、倍投分布
3. **全局汇总层**：按人群占比加权计算全局分布
4. **复式结构层**：复式/胆拖的内部结构明细

### 1.2 核心参数维度

| 维度 | 参数项 | 说明 |
|------|--------|------|
| 人群结构 | 高/中/低频占比 | 影响投注风格的基础分布 |
| 投注形式 | 单式/复式/胆拖占比 | 每类人群的投注方式选择 |
| 复式结构 | 复式规模分布 | 如7红/8-9红/10-12红的占比 |
| 胆拖结构 | 胆拖组合分布 | 如1胆+5拖/2胆+4拖的占比 |
| 倍投分布 | 1倍/2-5倍/6-20倍/20+倍 | 每类人群的倍投偏好 |
| 选号特征 | 热号/冷号/生日号占比 | 号码生成的偏好参数 |

### 1.3 现有方案的不足

1. **彩种特定**：每种彩票的参数模板不同，无法通用
2. **参数固化**：投注方式选项硬编码，无法扩展
3. **缺乏联动**：参数之间没有联动关系
4. **不支持自定义**：无法创建新的投注方案

## 二、通用投注参数系统设计

### 2.1 设计目标

1. **完全通用**：一套参数系统支持所有彩种
2. **灵活配置**：用户可自定义投注方式和参数
3. **智能适配**：根据彩种特性自动调整可用参数
4. **易于理解**：参数分类清晰，操作简单

### 2.2 参数分类体系

#### 第一层：人群结构（必选）

```
彩民人群结构
├── 低频彩民（占比 30-80%）
├── 中频彩民（占比 10-60%）
└── 高频彩民（占比 0-30%）
```

**规则**：三者之和必须为100%

#### 第二层：投注方式（必选）

```
投注方式
├── 单式投注（基础投注）
├── 复式投注（可选，彩种不支持则隐藏）
│   ├── 复式规模A（如7红）
│   ├── 复式规模B（如8-9红）
│   └── 复式规模C（如10-12红）
└── 胆拖投注（可选，彩种不支持则隐藏）
    ├── 胆拖组合A（如1胆+5拖）
    ├── 胆拖组合B（如2胆+4拖）
    └── 胆拖组合C（如3胆+3拖）
```

**规则**：单式+复式+胆拖之和必须为100%

#### 第三层：倍投分布（必选）

```
倍投分布
├── 1倍（基础倍数）
├── 2-5倍
├── 6-20倍
└── 20倍以上
```

**规则**：四项之和必须为100%

#### 第四层：选号特征（可选）

```
选号特征
├── 机选占比
├── 自选占比（生日/纪念日）
├── 走势分析占比
└── 守号占比
```

**规则**：四项之和必须为100%

#### 第五层：复式/胆拖内部结构（条件必选）

```
复式内部结构（仅当复式占比>0时显示）
├── 复式规模A占比
├── 复式规模B占比
└── 复式规模C占比

胆拖内部结构（仅当胆拖占比>0时显示）
├── 胆拖组合A占比
├── 胆拖组合B占比
└── 胆拖组合C占比
```

### 2.3 彩种适配规则

| 彩种 | 支持复式 | 支持胆拖 | 特殊参数 |
|------|:--------:|:--------:|----------|
| 双色球 | ✓ | ✓ | 红球复式、蓝球复式、红蓝复式 |
| 大乐透 | ✓ | ✓ | 前区复式、后区复式、双区复式、追加投注 |
| 福彩3D | ✓ | ✓ | 直选、组三、组六 |
| 排列三 | ✓ | ✓ | 直选、组三、组六 |
| 排列五 | ✗ | ✗ | 仅单式 |
| 七星彩 | ✓ | ✗ | 前区复式、后区复式 |
| 七乐彩 | ✓ | ✓ | 8-12码复式、13码+全复式 |
| 快乐8 | ✓ | ✓ | 选一~选十玩法占比 |

### 2.4 参数联动规则

1. **人群结构联动**：修改一类人群占比，其他两类自动调整保持100%
2. **投注方式联动**：修改单式占比，复式和胆拖自动按比例调整
3. **复式结构联动**：仅当复式占比>0时显示，且内部占比之和为100%
4. **胆拖结构联动**：仅当胆拖占比>0时显示，且内部占比之和为100%
5. **倍投分布联动**：四项之和必须为100%

## 三、预设投注方案设计

### 3.1 方案一：保守型（低风险）

```
人群结构：低频60% / 中频30% / 高频10%
投注方式：单式75% / 复式20% / 胆拖5%
```

### 3.4 方案四：官方数据型（真实市场）

```
人群结构：低频50% / 中频38% / 高频12%
投注方式：单式60% / 复式25% / 胆拖15%

```

```
├─────────────────────────────────────────────────────┤
│                                                     │
│  一、彩民人群结构占比                                 │
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐   │
```

### 5.2 交互特性

1. **实时校验**：修改参数时实时检查占比之和是否为100%
2. **智能联动**：修改一个参数，其他参数自动调整
3. **彩种适配**：根据当前彩种显示/隐藏不适用的参数
4. **预设切换**：一键切换预设方案
5. **导入导出**：支持JSON格式的配置导入导出
