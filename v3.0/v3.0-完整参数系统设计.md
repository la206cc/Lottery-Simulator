## 2. A类：彩票规则配置

### 2.1 基础信息

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `id` | string | ✅ | - | 彩票唯一标识（如 `ssq`、`dlt`） |
| `name` | string | ✅ | - | 彩票名称（如"双色球"） |
| `fullName` | string | ❌ | 同name | 完整名称（如"中国福利彩票双色球"） |
| `category` | enum | ✅ | - | 彩票类别：`数字型`、`乐透型`、`竞猜型`、`即开型` |
| `issueInterval` | enum | ❌ | `weekly` | 开奖周期：`daily`、`twice_daily`、`twice_weekly`、`weekly` |
| `pricePerBet` | number | ✅ | 2 | 单注价格（元） |
| `currency` | string | ❌ | `CNY` | 货币单位 |

### 2.2 号码区域配置

每个彩票可以有1~5个号码区域（Zone），每个区域独立配置：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `zones[].name` | string | ✅ | - | 区域名称（如"红球"、"前区"） |
| `zones[].min` | number | ✅ | 1 | 最小号码 |
| `zones[].max` | number | ✅ | - | 最大号码 |
| `zones[].count` | number | ✅ | - | 基本选取数量 |
| `zones[].repeatable` | boolean | ❌ | false | 是否允许重复（如快乐8） |
| `zones[].sorted` | boolean | ❌ | true | 是否排序显示 |
| `zones[].color` | string | ❌ | - | 显示颜色（如"red"、"blue"） |
| `zones[].allowExtra` | boolean | ❌ | false | 是否支持复式（多选） |
| `zones[].maxExtra` | number | ❌ | 20 | 复式最大选取数 |
| `zones[].allowDanTuo` | boolean | ❌ | false | 是否支持胆拖 |

**示例配置：**

```json
{
  "zones": [
    {
      "name": "红球",
      "min": 1, "max": 33, "count": 6,
      "repeatable": false, "sorted": true,
      "color": "red", "allowExtra": true, "maxExtra": 20,
      "allowDanTuo": true
    },
    {
      "name": "蓝球",
      "min": 1, "max": 16, "count": 1,
      "repeatable": false, "sorted": false,
      "color": "blue", "allowExtra": true, "maxExtra": 16,
      "allowDanTuo": false
    }
  ]
}
```

### 2.3 玩法类型配置（可选）

对于支持多种玩法的彩票（如3D、排列三），需要配置玩法类型：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `playTypes` | array | ❌ | 玩法类型列表 |
| `playTypes[].id` | string | ✅ | 玩法标识（如 `direct`、`group3`、`group6`） |
| `playTypes[].name` | string | ✅ | 玩法名称（如"直选"、"组选3"） |
| `playTypes[].matchType` | enum | ✅ | 匹配方式：`exact`（按位）、`any`（不按位） |
| `playTypes[].prizeMultiplier` | number | ❌ | 奖金倍数（相对于基本奖金） |
| `playTypes[].minBet` | number | ❌ | 最低投注注数 |
| `playTypes[].maxBet` | number | ❌ | 最高投注注数 |

**示例（福彩3D）：**

```json
{
  "playTypes": [
    { "id": "direct", "name": "直选", "matchType": "exact", "prizeMultiplier": 1.0 },
    { "id": "group3", "name": "组选3", "matchType": "any", "prizeMultiplier": 0.5 },
    { "id": "group6", "name": "组选6", "matchType": "any", "prizeMultiplier": 0.333 }
  ]
}
```

## 3. B类：奖金分配配置

### 3.1 奖级配置

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `prizes` | array | ✅ | 奖级列表（按等级从高到低） |
| `prizes[].level` | number | ✅ | 奖级（1=一等奖，2=二等奖...） |
| `prizes[].name` | string | ✅ | 奖级名称 |
| `prizes[].matchPattern` | array | ✅ | 中奖条件（见下文） |
| `prizes[].fixed` | boolean | ✅ | 是否固定奖金 |
| `prizes[].amount` | number | 固定时必填 | 固定奖金金额（元） |
| `prizes[].poolRatio` | float | 浮动时必填 | 浮动奖金占比（0~1） |
| `prizes[].maxPerTicket` | number | ❌ | 单注封顶金额 |
| `prizes[].maxTotal` | number | ❌ | 该奖级总奖金封顶 |
| `prizes[].minPerTicket` | number | ❌ | 单注保底金额 |
| `prizes[].addOnMultiplier` | float | ❌ | 追加奖金倍数（如1.8） |
| `prizes[].maxAddOnPerTicket` | number | ❌ | 追加单注封顶 |

### 3.2 matchPattern 匹配规则

`matchPattern` 是一个二维数组，表示中奖条件。格式：

```json
[[zone1命中数, zone2命中数, ...], [另一种中奖条件]]
```

**示例：**

| 彩种 | 奖级 | matchPattern | 说明 |
|------|------|--------------|------|
| 双色球一等奖 | 1 | `[[6, 1]]` | 红球6个 + 蓝球1个 |
| 双色球二等奖 | 2 | `[[6, 0]]` | 红球6个 + 蓝球0个 |
| 双色球三等奖 | 3 | `[[5, 1]]` | 红球5个 + 蓝球1个 |
| 福彩3D直选 | 1 | `[[1, 1, 1]]` | 三位数按位全中 |
| 福彩3D组选3 | 1 | `[[2]]` | 两位数（不按位） |
| 快乐8选十 | 1 | `[[10]]` | 10个号码全中 |

### 3.3 奖池分档配置

对于有奖池分档规则的彩票：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `poolTiers` | array | ❌ | 奖池分档规则 |
| `poolTiers[].min` | number | ✅ | 奖池最低值（元） |
| `poolTiers[].max` | number | ❌ | 奖池最高值（null=无上限） |
| `poolTiers[].firstPrizeRatio` | float | ✅ | 一等奖占比 |
| `poolTiers[].secondPrizeRatio` | float | ❌ | 二等奖占比 |
| `poolTiers[].secondPartRatio` | float | ❌ | 一等奖第二部分占比（高奖池时） |

**示例（双色球）：**

```json
{
  "poolTiers": [
    {
      "min": 0, "max": 100000000,
      "firstPrizeRatio": 0.75,
      "secondPrizeRatio": 0.25,
      "secondPartRatio": null
    },
    {
      "min": 100000000, "max": null,
      "firstPrizeRatio": 0.75,
      "secondPrizeRatio": 0.25,
      "secondPartRatio": 0.15
    }
  ]
}
```

### 3.4 保底规则配置

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `guaranteeRules` | array | ❌ | 保底规则列表 |
| `guaranteeRules[].level` | number | ✅ | 受影响的奖级 |
| `guaranteeRules[].condition` | string | ✅ | 保底条件表达式 |
| `guaranteeRules[].triggerLevel` | number | ❌ | 触发保底的奖级 |
| `guaranteeRules[].cascade` | boolean | ❌ | 是否级联触发其他保底 |

**示例（双色球）：**

```json
{
  "guaranteeRules": [
    {
      "level": 2,
      "condition": "min(6000)",
      "description": "二等奖单注不低于6000元"
    },
    {
      "level": 1,
      "condition": "min(prize2 * 2, 5000000)",
      "triggerLevel": 2,
      "cascade": true,
      "description": "一等奖不低于二等奖×2，封顶500万"
    }
  ]
}
```

### 3.5 特殊功能开关

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `canAddOn` | boolean | false | 是否支持追加投注 |
| `addOnPrice` | number | 1 | 追加投注单价（元） |
| `addOnRatio` | float | 0.8 | 追加奖金提升比例（如0.8=提升80%） |
| `hasSpecialNumber` | boolean | false | 是否有特别号码（如快乐8的金码） |
| `specialNumberZone` | string | - | 特别号码所在区域 |
| `hasReversePrize` | boolean | false | 是否有倒置规则（如七星彩） |
| `reverseThreshold` | number | - | 倒置触发的奖池门槛 |

## 4. C类：投注模拟配置

### 4.1 投注类型分布

模拟真实用户的投注习惯：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `betType.singleRatio` | float | ✅ | 0.60 | 单式投注占比 |
| `betType.complexRatio` | float | ✅ | 0.30 | 复式投注占比 |
| `betType.danTuoRatio` | float | ✅ | 0.10 | 胆拖投注占比 |

**复式内部结构（可选）：**

| 参数名 | 说明 |
|--------|------|
| `betType.complexRed7Ratio` | 红球7个的比例 |
| `betType.complexRed8Ratio` | 红球8个的比例 |
| `betType.complexRed9Ratio` | 红球9个的比例 |
| `betType.complexRed10PlusRatio` | 红球10+个的比例 |

**胆拖内部结构（可选）：**

| 参数名 | 说明 |
|--------|------|
| `betType.dan1Tuo5Ratio` | 1胆5拖的比例 |
| `betType.dan2Tuo4Ratio` | 2胆4拖的比例 |
| `betType.dan3Tuo3Ratio` | 3胆3拖的比例 |

### 4.2 倍投分布

| 参数名 | 类型 | 必填 | 默认值 | 说明 |

| `multiplier.ratio1x` | float | ✅ | 0.75 | 1倍投注占比 |
| `multiplier.ratio2_5x` | float | ✅ | 0.20 | 2-5倍投注占比 |
| `multiplier.ratio6_20x` | float | ✅ | 0.045 | 6-20倍投注占比 |
| `multiplier.ratio20xPlus` | float | ✅ | 0.005 | 20倍以上占比 |
| `multiplier.maxMultiplier` | number | ❌ | 100 | 最大倍数限制 |

### 4.3 销量波动模拟

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `sales.baseSales` | number | ✅ | - | 基准销量（万注） |
| `sales.fluctuation` | float | ✅ | 0.10 | 销量波动幅度（±10%） |
| `sales.trend` | enum | ❌ | `stable` | 趋势：`up`、`down`、`stable` |
| `sales.trendRate` | float | ❌ | 0 | 趋势变化率 |

### 4.4 投注限制

| 参数名 | 类型 | 默认值 | 说明 |

| `limits.maxAmountPerIssue` | number | 10000 | 每期最大投注金额 |

## 9. 资金计算规则详解

### 9.1 基础计算公式

```
投注成本 = 单注价格 × 注数 × 倍数 + 追加金额
```

### 9.2 复式注数计算

```
复式注数 = C(红球选取数, 基本红球数) × C(蓝球选取数, 基本蓝球数)
```

### 9.3 胆拖注数计算

```
胆拖注数 = C(拖码数, 基本数 - 胆码数)
```

### 9.4 浮动奖金计算

```
浮动奖池 = 总奖池 - 固定奖金总额

一等奖金额 = 浮动奖池 × 一等奖占比
一等奖单注 = min(一等奖金额 / 中奖注数, 单注封顶)
```

### 9.5 两部分封顶（双色球/大乐透高奖池）

```
第一部分 = 奖池资金 + 浮动奖池 × 基础占比
第二部分 = 浮动奖池 × 第二部分占比

单注总额 = min(第一部分/注数, 500万) + min(第二部分/注数, 500万)
理论最大 = 1000万/注
```

### 9.6 追加奖金计算（大乐透）

```
追加单注 = 基本单注 × 1.8
追加封顶 = min(追加单注, 900万)
```

### 9.7 保底级联规则

```
步骤1：检查二等奖保底
  如果 二等奖单注 < 6000（双色球）或 三等奖×2（大乐透）
    则 二等奖单注 = 保底金额

步骤2：检查一等奖保底
  如果 一等奖单注 < 二等奖单注 × 2
    则 一等奖单注 = min(二等奖单注 × 2, 500万)
```

## 10. 易错点与边界条件

### 10.1 整数溢出

| 场景 | 风险 | 解决方案 |
|------|------|----------|
| 超大量模拟（10亿注） | 注数×单价可能超出32位整数 | 使用64位整数（Python默认支持） |
| 奖池计算 | 奖池可能达到百亿级 | 使用Python int（任意精度） |

### 10.2 浮点精度

| 场景 | 风险 | 解决方案 |
|------|------|----------|
| 奖金占比计算 | 浮动比例相乘可能产生精度误差 | 先计算总额，再除以注数 |
| 追加倍数 | 1.8倍可能产生小数 | 使用 `int()` 截断或 `round()` 四舍五入 |

### 10.3 边界条件

| 场景 | 正确处理 |
|------|----------|
| 中奖注数为0 | 该奖级奖金为0，不触发封顶/保底 |
| 奖池为0 | 浮动奖金为0，只发固定奖 |
| 所有奖级无人中 | 奖金滚入下期（需配置） |
| 追加投注但彩票不支持 | 忽略追加标志 |
| 胆码数 >= 基本数 | 非法配置，需校验拒绝 |

### 10.4 保底规则顺序

**正确顺序（必须严格遵守）：**

1. 先计算所有奖级的基础金额
2. 应用保底规则（按配置顺序）
3. 检查是否触发级联
4. 最后应用封顶规则

**错误示例：**

```python
# ❌ 错误：先检查封顶再检查保底
if first_prize > max_per_ticket:
    first_prize = max_per_ticket  # 封顶了
if first_prize < second_prize * 2:
    first_prize = second_prize * 2  # 可能超过封顶！

# ✅ 正确：先保底再封顶
if first_prize < second_prize * 2:
    first_prize = min(second_prize * 2, max_per_ticket)
```
