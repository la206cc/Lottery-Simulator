功能说明

投注参数独立类目：

投注模拟参数现在是一个独立的表单区块，包含投注类型分布（单式/复式/胆拖占比）和倍投分布（各倍数区间占比、最大倍数）。这使得参数配置更加清晰，便于用户理解和调整。

主页显示当前彩种名称：

主页现在会显示当前配置的彩种名称。当用户在配置编辑器中选择或保存配置时，主页会自动更新显示当前彩种的名称和基本信息（如单注价格）。这提供了更好的用户体验，让用户随时知道当前正在使用的彩票配置。
