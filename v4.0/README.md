# 逆向开奖台 4.0

一个围绕“开奖结果由投注分布人为操作”假说构建的本地彩票反事实模拟器。它使用双色球和超级大乐透的真实公开开奖数据，生成合成投注人群，搜寻落在一等奖人数目标区间内的候选开奖组合，并计算完整奖级和预期返奖。

> 这不是预测器。真实彩票开奖独立随机，任何历史分析、模拟评分或“反向推测”都不能提高中奖概率，也不能保证收益。

## 已实现

- 从中国福利彩票、中国体育彩票官方公开接口同步真实开奖。
- 内置双色球、大乐透各 1,000 期已开奖数据，可继续增量刷新。
- 根据真实销售额估算投注规模，根据历史、生日号、吉利/避讳号构造合成投注人群。
- 从最多 30,000 组候选开奖中筛选目标一等奖人数区间。
- 按当前规则完整结算双色球 6 个奖级、大乐透 9 个奖级。
- 展示预期一等奖、二等奖、总中奖、总返奖、返奖比例、人群暴露度和历史结构拟合度。
- 支持无穿越历史回测：逐期只用开奖前数据生成候选，再与真实开奖比较。
- 同时给出回测命中率、理论随机基线、95% 置信区间和相对中性参数的差异。
- 把五组预测逐一作为实际投注单结算，并比较常见小额复式。
- 提供多目标返奖、反热门、双层稳健、走势状态及四模型综合排序。
- 支持固定随机种子复现实验，可导出真实开奖 CSV。

## 启动

双击 `start.bat`，或在 PowerShell 中运行：

```powershell
cd "G:\Desktop\彩票模拟\Lottery-Simulator\v4.0"
py -m backend.server
```

浏览器会打开 `http://127.0.0.1:8400`。项目只使用 Python 标准库，不需要安装第三方依赖。

也可以直接从命令行选号：

```powershell
py -m backend.cli --lottery ssq --min 5 --max 7
py -m backend.cli --lottery dlt --min 4 --max 6
```

## 更新数据

界面右上角可以增量刷新当前彩种。命令行一次更新两个彩种：

```powershell
py -m backend.refresh_data --lottery all --limit 1000
```

原始数据保存在 `data/raw/ssq.json` 和 `data/raw/dlt.json`，每条记录保留期号、日期、开奖号码、销售额、奖池、各奖级注数和单注金额。

官方数据入口：

- 双色球：[中国福利彩票发行管理中心](https://www.cwl.gov.cn/)
- 超级大乐透：[中国体育彩票](https://static.sporttery.cn/)

## 反推算法

1. **真实画像**：统计近期号码频率、遗漏、和值分布、跨度、一等奖人数和销售额。
2. **合成投注**：用多种人群画像生成票样，包括均匀随机、追热号、生日号、吉利/避讳号和重复旧票。
3. **候选池**：从均匀组合、符合人群倾向的组合、冷门组合和混合组合中生成候选开奖。
4. **约束搜索**：用加权无放回抽样概率估算每组候选的一等奖人数，筛选目标区间。
5. **完整结算**：用加权无放回抽样的精确命中概率计算全部奖级注数和返奖；固定票样同时用于交叉检查。
6. **结果排序**：优先目标区间拟合、历史号码结构和较低人群暴露，并限制推荐组合之间的高度重叠。

## 历史回测

页面中的“用过去验证下一期”会对最近 10–50 期逐一执行以下流程：

1. 截断该期开奖及之后的数据。
2. 只使用此前历史生成组合器中指定数量的候选号码（1–10 组）。
3. 与真实开奖逐注匹配，计算所有奖级。
4. 将每组预测逐一与真实开奖比较，显示每张票、每个展开组合的奖级和奖金。
5. 在相同历史期和随机种子下运行中性参数，展示参数差异。

复式回测支持：

- 双色球：红球 6–9 个号码与蓝球 1–3 个号码组成的全部 12 种小额类型。
- 超级大乐透：前区 5–9 个号码与后区 2–4 个号码组成的全部 15 种小额类型。

复式不是简单补上相邻号码。模型先从满足目标头奖区间的候选集合计算各号码的预测支持度，再针对每张复式票联合选择补位号码，并对多张票重复使用同一补位的做法施加惩罚。新增号码在界面中以虚线球显示。例如双色球五张 `7+1` 票，每期总计 35 注、成本 70 元；大乐透五张 `7+2` 票，每期总计 105 注、成本 210 元。回测按每张组合票单独计算奖级和奖金。

界面提供 8 种套票模板作为起点。用户可以在模板基础上逐组修改单式或复式类型、增加或删除预测组；回测只读取用户最终确认的组合，不限制为纯单式、纯复式或固定五组。每期总注数和总成本会在运行前实时计算。

回测采用 walk-forward 方式，避免把目标期及其未来数据泄漏到选号过程。报告同时给出每注任意奖的理论随机概率。即使某组参数在短回测中表现更好，也不能据此认为真实中奖概率提高；这通常只是小样本波动或参数过拟合。

## 推演策略

- **多目标返奖控制**：联合考虑一等奖人数、目标返奖率和历史号码结构。
- **反热门组合**：降低预计投注重叠，优先选择不属于人群常见扎堆形态的候选。
- **双层稳健博弈**：在当前、中性、追热号、生日号和吉利避讳五类投注人群下评估头奖人数，惩罚跨场景波动。
- **走势状态转移**：按和值区间和奇偶结构划分状态，用近期状态转移概率筛选候选。
- **四模型综合**：按可解释权重汇总上述四类指标，并展示每项的 0–100 分拆解。
- **原基础模型**：保留此前的头奖区间控制方案，用作对照。

策略可以在主选号区和历史回测区分别选择，并共享目标返奖率、投注组合、随机种子和数据窗口。模型评分始终是假设拟合度，不是真实中奖率。

一等奖期望人数使用如下形式计算：

```text
预期一等奖人数 = 本期总注数 × 主区组合权重概率 × 特别号区组合权重概率
```

权重来自合成人群参数，不是真实逐号销量。全部奖级按主区和特别号区的精确命中分布计算，避免低概率奖级被抽样噪声放大。当前模型不计追加投注。

## 必须知道的限制

- 真实逐注投注数据不公开，因此“投注人群”是根据公开信息构建的仿真假设。
- 官方公开数据可以验证开奖结果，但无法证明开奖是否被人为操控。
- 目标中奖人数和返奖比例属于模型估计，不是未来事件概率。
- 模型拟合度高只表示结果更符合当前假设，不代表更可能中奖。
- 当前规则按公开基础投注结算，不包含派奖活动和追加投注。
